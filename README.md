# 🎮 Simon Says Game

A browser-based Simon Says memory game built as part of my Web Development learning journey during my first semester.

## 🌐 Live Demo

**[Click here to play the game](https://rudramishra2007.github.io/Simon-Says-Game/)**

## 📖 About the Project

Simon Says is a memory game where players must remember and repeat a sequence of colors in the correct order.

As the game progresses, the sequences become longer, challenging the player's memory and concentration.

I created this project while learning Web Development through Apna College.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ✨ Features

- Interactive gameplay
- Color-based memory challenges
- Dynamic game sequences
